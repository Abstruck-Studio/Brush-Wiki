Brush Wiki

Brush 是一个自研的 Minecraft 26.1.2 客户端模组加载器。它的核心卖点是 「写一次，一个 jar 跑三种运行时」 —— S1 纯 Brush、 S2 Fabric 宿主、S3 NeoForge 宿主。26.1 起游戏未混淆，三个运行时的类名与方法名完全一致， 因此不需要任何重映射、也不需要为平台分别构建。

下载 MDK（26.10.1）：Brush-MDK-26.10.1.zip（约 66 KB）—— 解压后项目根就是可运行的 Gradle 工程， 加载器与能力库默认从网络库取。上手步骤见下方 「快速开始（MDK）」，完整接线与模板见 第一个 mod（MDK 上手）。

三种运行时

运行时形态启动生态共存
S1纯 Brush vanilla + Brush 自己的 ClassLoader 与注入层 gradlew runClient 只加载 Brush 生态的 mod
S2Fabric 宿主 Fabric Loader（Knot）之上叠加 Brush gradlew runFabricClient Fabric mod 与 Brush mod 同一 JVM 共存
S3NeoForge 宿主 FML / NeoForge 之上叠加 Brush gradlew runNeoForgeClient Neo mod 与 Brush mod 同一 JVM 共存
叠加（overlay）而非寄生。Brush 不把自己变成某个宿主的普通 mod 而永久依赖它： 同一份字节码在 vanilla 上也能独立跑起来（S1）。这是 HostAdapter 抽象与「薄注入」设计的直接结果， 详见 三运行时与宿主适配。

快速开始（MDK）

开发包（MDK）是一个扁平的 Gradle 项目：解开压缩包后 build.gradle / src/ / wrapper 都在根目录。它默认从网络库取加载器与能力库；命令都在项目根执行：

gradlew.bat jar            :: 编译你的 mod（构建期自动下 MC 客户端 jar；产物 build\libs\mdkexample.jar）
gradlew.bat runClient      :: 启动游戏（S1）：先摆好"你的 mod + brush-api"，再拉起游戏
gradlew.bat bootstrap      :: 可选：一次性备齐客户端 jar + 库 + natives + assets

MDK 现在三种运行时都能直接跑：runClient（S1）/ runFabricClient（S2）/ runNeoForgeClient，harness 来自那个 tools classifier。 离线或想完全自包含就传 -Pbrush.useLocalJars=true —— 那时改用你自己放进 libs/ 的 jar。 细节见 第一个 mod（MDK 上手）。
